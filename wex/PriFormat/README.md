# PriFormat (third-party, Apache-2.0)

A reader for Package Resource Index files (`resources.pri`), from PriTools by Christoph Hausner
(https://github.com/chausner/PriTools, folder `PriFormat`, commit 765d454), licensed under the Apache License 2.0
(the same licence as this repository, `../../License.md`). Copied unchanged except for this file; XamlShim uses it to
read compiled XAML (`.xbf`) embedded in an application's `resources.pri`.
